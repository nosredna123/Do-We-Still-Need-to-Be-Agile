Overview

Browse three research questions about perceptions, activity, and coordination in student projects using generative AI. These are descriptive and exploratory observations, not causal evidence or a ranking of teams.

  • RQ1: Self-report and coded perceptions

    M1-M2: reported AI use, coded perceptions, and role perceptions. Survey summaries do not measure actual AI-use telemetry.

  • RQ2: Repository activity and transcript evidence

    M3-M5: participation, code change, and lexical aggregates. Repository and transcript evidence have different analytical grains.

  • RQ3: Planning, inactivity, rework, and associations

    M6-M9: structural and content evidence, timing, rework eligibility, and published exploratory associations.

Understand the evidence grain

Each dataset has a specific unit of observation. Similar labels do not make datasets interchangeable or authorize joining them.

Survey summaries
Aggregated by cohort and checkpoint, with role or category where documented. There is no team key; responses cannot be assigned to project teams.
Repository activity
Team-semesters are identified by cohort plus team, not by the repeated team label alone. Checkpoint and window keys must also be retained where present. Coverage spans 14 team-semesters: nine in 2025.2 and five in 2026.1.
Transcript lexical aggregates
One measured 2025.2 corpus, summarized by checkpoint, not individual teams. No transcript measurements are available for 2026.1.
Published summaries and associations
Fixed published populations and original sample sizes. Estimates are not recalculated for a selected subset.

Missing is not zero. Unavailable measurement, ineligible observation, an empty selection, and a failed load are different states.

Data selection and reuse guide

  1. Choose the evidence. In Explore, narrow the research question, metric and evidence source, then choose a dataset. Read its definition, grain, keys, coverage and limitations before filtering. Team-semester identity is cohort plus team; repeated team labels are not the same case. These navigation choices choose datasets, not observation rows. Survey summaries and the global transcript corpus do not support team attribution. Only the dataset's permitted filters are available. None selected means all; selected values within a group use OR and groups use AND. Changing datasets resets incompatible selections.
  2. Check units and denominators. Read column definitions beside the table or use definition search below. Counts, changed lines, score points, fractions, percentages and markers per 1,000 tokens are different units. A fraction from 0 to 1 is not a percentage from 0 to 100; score points are not percentage points. Preserve original Ns and denominators; the visible row count is not a new participant sample size. Null/Unavailable, observed zero, false, an empty filter result and a load error have different meanings. Consult measurement and ratio status fields. Use the visible retry control after a load error; do not treat it as absent evidence.
  3. Record the snapshot. Use Snapshot and provenance and the release manifest for the snapshot ID, schema version, coverage and original-file hashes. Keep the dataset ID, downloaded files and matching scope metadata together; do not mix snapshots. The manifest hashes original public data artifacts, not generated filtered CSVs or the entire site. A snapshot identifier is not a license or proof of publication or anonymity approval. The development preview remains subject to the publication gates.
  4. Choose the download scope. Full CSV and typed JSON links always contain all original rows of the selected dataset. Displayed-row CSV follows only the observation table's current filters and sort; save its matching export scope and column-definitions JSON too. Empty selections yield headers only and zero selected rows in metadata. Chart zoom and legend visibility do not filter exports. In a multi-source figure, only the selected exact source is filtered/exported; the other panel is not joined or included. Reset row filters and sort restores all source rows; Reset figure view changes the view, not the row selection.
  5. Import without changing values. Use a CSV-aware import tool with UTF-8 encoding, comma delimiter and double-quote text qualifier; quoted fields can contain commas or newlines. Assign text types to cohort, team and category identifiers, and numeric/boolean types according to the companion definitions. Treat empty CSV cells as null, never zero, false or a value to fill forward. Preserve original IDs and status columns. Do not open-and-resave through automatic spreadsheet conversion: it can change identifiers or round numbers. Quoting is not a safety guarantee; formula-leading text is rejected rather than altered. Keep original files unchanged; use typed JSON if the import tool cannot preserve the types and numeric precision. JSON is structured data, not spreadsheet cell text.
  6. Preserve interpretation limits. These observations and associations are descriptive and exploratory, not causal estimates or team rankings. Filters select existing rows; pooled estimates, thresholds, median guides and original Ns stay fixed. SD bars are not confidence intervals. An absent repository artifact does not prove no planning, and rework is not a defect count. Ineligible ratios remain unavailable even when a magnitude exists; logarithmic charts omit zero magnitudes without changing their source-table values. Do not infer individual or team transcript observations, unmeasured-cohort evidence, or new subset correlations. The transcript corpus covers 2025.2 only, not 2026.1. Evaluator score points are not repository structural complexity. No verbatim quotations are released here. Preserve privacy boundaries and do not attempt to re-identify participants.

Frozen scientific policies and thresholds

Scales, eligibility, and interpretation

Perception scales
M1 coded perception scores use 0-4. Raw autonomy categories and M2 Likert responses use 1-5; these scales are not interchangeable.
Unavailable and empty evidence
Unmeasured planning-content fields are null, not zero. Successfully measured empty evidence can be an observed zero. Absent rows are not synthesized.
Rework eligibility
Ratios require an observed baseline and a nonzero clean-churn denominator. Ineligible ratios are null with an explicit status. Rework is not a defect count.
Fixed estimates
Pooled summaries, association estimates, thresholds, and original sample sizes remain fixed. Leave-one-out diagnostics are not confidence intervals.
Exact values
Approved JSON and CSV files preserve the same rows, columns, and scientific precision. Empty CSV cells represent null values, not numeric zero.
